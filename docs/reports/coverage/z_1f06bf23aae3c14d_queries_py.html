1"""PyMySQL data access for the Category/Department module. 

2 

3Every function takes an open cursor (rows come back as dicts, see db.connection) and only runs 

4parameterised SQL (SEC-003). Nothing here commits or rolls back: the caller owns the transaction. 

5 

6Other modules reuse these instead of querying the tables themselves: 

7 get_active_category Complaint submission (#17): is this category usable? 

8 get_department_staff_member Complaint assignment (#19): may this user take work for this department?

46def name_taken(cur, name, exclude_id=None): 

47 """True if another category already has this name. 

48 

49 The comparison uses the column's collation, the same rule as the uq_categories_name key 

50 (case- and accent-insensitive), so this check and the database agree. 

51 """ 

52 sql = "SELECT 1 FROM categories WHERE name = %s" 

53 params = [name] 

54 if exclude_id is not None: 

55 sql += " AND category_id <> %s" 

56 params.append(exclude_id) 

57 cur.execute(sql, params) 

58 return cur.fetchone() is not None
